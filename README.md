# CineFlix — Next.js 14 (App Router)

Full export of the CineFlix site as a Next.js 14 + TypeScript + Tailwind project.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build && npm start
```

## Notes
- All UI components, hooks, animations and design tokens are preserved 1:1.
- Images live under `public/assets/` and are referenced as `/assets/<file>.jpg`.
- Interactive components are marked with `"use client"`.
